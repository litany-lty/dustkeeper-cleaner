### 4.1 `review unknown` 打开状态库（真实 panic）

- `cmd/dustkeeper/cmd_review.go`：`list` 与 `resolve` 前显式 `a.openStore()`。`withInstance` 只拿实例锁
  和打开操作日志，不打开状态库，所以两个子命令原先都在解引用 `nil`。
- 修前复现（真实二进制）：`review unknown list` 与 `resolve` 均 `SIGSEGV`，
  `store.(*Store).read/write` on nil receiver。
- 修后：无实例 → `INVALID_ARGUMENT: … run 'dustkeeper init' first`；已初始化 → `OK / count 0`；
  无 `--confirm` → `NEEDS_INPUT`（exit 2）。
- 反证：`cmd/dustkeeper/cmd_review_test.go` 两个用例覆盖无实例不崩、有实例列表、路径解码、
  `cost_status=unknown`、`--confirm`/`--note` 缺一拒绝、resolve 后开放列表为空而 `--all` 保留历史行。

### 4.2 下一候选预留两次 HTTP 尝试

  `已用 + 2 > 上限` 则不启动；`batch_max_attempts: 1` 仍是合法配置，但一个候选都不会开始。
