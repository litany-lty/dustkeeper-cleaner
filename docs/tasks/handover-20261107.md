   核对整个实例的 scope、对账队列、到期对象与授权范围；不能把"只预览了一条规则"当成"整轮只动一个目录"。

   状态库及 sidecar、各 scope 完整 `.dustkeeper/`、旧二进制 + `version` 输出 + SHA-256）。自定义
   `result-dir` 不在采集白名单时，另存实际结果页并标注来源与 run ID。
