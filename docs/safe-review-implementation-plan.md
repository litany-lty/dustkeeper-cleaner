# 证据约束的双重判断实施计划

状态：本地开发；正式实例保持暂停，不部署、不永久删除、不调用真实模型。

目标：在既有隔离和清空执行器上增加共同门禁。规则只筛候选；缺证据、任一模型否决、失败或过期均保留。

本轮保守范围：逐文件登记用途、可丢弃理由、内容 SHA-256、有效期，以及清理范围外的独立保留副本；副本须存在、普通文件、非同 inode/硬链接、全路径无符号链接、内容一致。不存在这些证据时不请求模型。仅可重新下载的推测本轮不作为证据。

- [x] review：本地证据校验、JEV choice 初判、MiniMax Anthropic 复核。输入不含文件内容、绝对路径、密钥，第二模型独立判断。
- [x] executor/store：Q 与 P 共用门禁；网络请求在文件临界区和事务外；哈希/保留副本再检查在 intent 前；审核记录与 intent 原子落库。恢复和对账不受模型阻塞。
- [x] config：只引用私有凭据文件/环境变量；可复用本地配置的显式导入脚本，不执行 shell 配置。无审核配置不能继续 Q/P。
- [x] 定向验证：缺证据、错副本、不同意、模型失败、审核过期/绑定不符、审核落库失败时无移动/删除；保留既有生命周期测试的独立假审核装置。
- [x] 文档：现状差距、实际本地证据、真实模型与正式部署未验证项、下一步改进与启用条件。

不变：schema 3、旧合同/manifest、既有独立清空授权和保留期，不把模型结论变成授权。审核不缓存复用，每次 Q/P 重新判断。用已有 events 持久化审核，无需为本轮增加迁移。

限制：副本一致证明内容可恢复，不证明文件对用户无价值；用途和可丢弃理由须明确登记，双模型仍可能共同误判。只记录事实，不宣称零误删。已提交 intent 的恢复按原合同收敛，不中途加入网络依赖。正式启用仍需真实模型评测与独立授权。
